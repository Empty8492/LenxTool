# Lenx Tools 威胁模型

## 资产

- 用户自备 Groq/DeepSeek Key、登录/刷新令牌、邀请码和管理员权限。
- 共享服务商 Key、每日额度、共享订阅目录、AI 策略、自动化规则及其版本、幂等写入记录、审计完整性和签名更新链路。
- 本地新闻/全文、图片缓存、AI 结果、私人阅读状态、收藏/标签/备注、字幕、规则运行与动作账本、媒体投递、应用内通知、用户文件路径和模型。
- 发布私钥（仅离线环境存在，永不进入客户端、Worker 或仓库）。

## 信任边界

1. WPF 输入、剪贴板、拖放文件与外部链接进入客户端。
2. 客户端与新闻源、Groq、DeepSeek、GitHub/镜像和 Worker 之间的 HTTPS。
3. WebView2 中不可信 HTML/Markdown 与本机应用之间的边界。
4. Worker 与匿名客户端、已认证 user、已认证 admin、D1、Groq/DeepSeek Secret 之间的边界。
5. 更新清单/安装包从发布环境进入客户端执行环境。
6. SQLite、DPAPI 文件、日志、模型和临时媒体位于同一 Windows 用户边界内。
7. 管理员提交的 Feed URL/显示元数据经 Worker 进入共享目录，再由各桌面端当作不可信配置读取；目录写路由本身不访问该 URL。
8. 管理员发布的 AI 策略和受限自动化规则经 Worker/D1 进入普通用户客户端；服务端负责 RBAC/版本，客户端仍必须对白名单字段、操作符、动作和大小再次验证。
9. 共享 AI/语音请求可在 Worker 请求生命周期内处理中转正文或媒体字节，但不得写入 D1、R2、KV、日志或审计；请求完成或取消后不保留内容。

## STRIDE 与控制

| 威胁 | 主要滥用场景 | 控制与测试 |
|---|---|---|
| 冒充 | 窃取 refresh token、伪造管理员、伪造服务商 | access token 仅驻内存、refresh token 使用 DPAPI CurrentUser、刷新轮换与撤销、RBAC 每端点校验、TLS、请求 ID |
| 篡改 | 修改 D1 用量/目录、重放管理员写入、并发或旧快照覆盖新版目录、替换 SQLite 或更新包 | 参数化 SQL、事务、条件额度更新、目录 `If-Match`、幂等 key、服务端/本地单调版本、本地原子快照替换、签名清单、SHA-256、内置公钥 |
| 抵赖 | 管理员否认发码/改额/改 Feed，用户否认共享调用 | 仅记录元数据的审计事件、操作者/目标/目录版本/时间/请求 ID；禁止记录正文和 token |
| 信息泄露 | Key/摘要进入响应或日志，音频落云，目录泄露本机信息，WebView2 读取本机 | DTO 字段白名单、DPAPI CurrentUser、日志过滤、Worker 不落正文、禁脚本/受控导航、最小响应字段 |
| 拒绝服务 | 巨型 JSON/批次/目录、热点源挂起、无限 AI、注册爆破 | 逐端点输入上限、目录容量与响应上限、批次最多 100 项、流式处理、每源超时/取消、队列并发 1、速率限制、每日额度 |
| 权限提升 | 普通用户调用管理员目录端点、客户端篡改 role、用错误响应探测管理员资源 | 角色只以服务端签名令牌和 D1 当前用户为准；授权先于幂等/版本/资源检查；每个管理员写入服务端授权和审计 |

## 关键滥用用例

- 同一用户并发发起多个共享转写，试图全部在扣费前通过。服务端必须原子预留额度；无余额的请求在调用 Groq 前失败。
- 普通用户直接调用分类、Feed 或批量写端点，或篡改本地 `IsAdmin`。Worker 必须先验证 access token、D1 禁用状态和 admin 角色，再读取幂等记录、目录版本或目标资源；未登录返回 401，已登录非管理员返回 403。
- 同一桌面会话并发收到多个 401，试图触发 refresh token 重放或让请求无限重试。客户端以会话代次和单飞门闩只执行一次刷新，每个请求最多重放一次；旧 refresh token 被 Worker 原子轮换后永久失效，失败会话从内存和 DPAPI 清除。
- 攻击者在首次部署期间抢先初始化管理员或从终端历史窃取凭据。bootstrap 只接受至少 32 个字符的临时 Worker Secret，先验 secret 再检查账号状态，使用空库条件写入保证最多一个成功者，并受认证限流；受控脚本通过安全提示读取密码/token，不接受敏感命令行参数。成功验证登录后立即删除 Secret，端点随即表现为 404。
- 两个管理员基于同一旧目录并发修改，或攻击者重放成功请求。所有目录写入必须在同一事务内比较 `If-Match`、应用业务变更、递增全局版本、写审计和幂等结果；旧版本返回 409，同 key/同请求只重放原响应，同 key/不同请求返回 409。
- 管理页面在 401 后重放目录写入、409 后误自动覆盖，或远端写入成功但本地同步失败后继续使用旧版本。桌面客户端在一次逻辑操作中固定 `Idempotency-Key`，409 只刷新快照并要求重新核对，不自动重放；若新版本未同步到本地，则锁定全部后续写命令。角色在异步刷新中降级时，加载边界会再次检查会话并清空 ALL 投影。
- 客户端收到乱序、旧版本或中途损坏的目录快照。本地仓储必须在任何删除前拒绝版本倒退，并在同一 SQLite 事务中替换分类、Feed 和状态；约束失败或取消后读者继续看到上一完整版本，本地文章不随目录移除而删除。
- 恶意管理员或被盗管理员账号提交内网、环回、含凭据或重定向到保留地址的 Feed URL。目录写路由只做有界语法规范化、绝不抓取；发现服务默认只允许公网 HTTPS/443，DNS 结果经 IPv4/IPv6 分类后直接钉住到无代理连接，每次重定向重新校验，并限制连接/总超时、跳转、候选数、压缩/解压大小、MIME 和 XML DTD/实体。HTTP 与内网主机必须分别精确配置，内网 HTTP 同时满足两项。
- 恶意或失控的发现 provider 通过挂起、429、巨型/畸形 JSON、无界候选、伪造高置信来源证据或夹带危险元数据拖垮或欺骗聚合结果。协调器为每个 provider 独立限制等待/执行超时、并发、成功缓存、候选数和熔断窗口；Worker 目录响应在 512 KiB 内逐字段映射，候选 URL、文本、枚举、目录身份、证据和警告均先验证。全部证据及具名警告必须归属于实际 provider，异常文本不进入结果；一个来源失败只标记部分结果，调用方取消继续向下传播。RSSHub/外部平台在官方接口与条款审核前不注册。
- 服务端回滚、损坏或网络乱序让客户端收到比本地更旧的目录版本。服务端拒绝 `afterVersion` 超前请求；客户端拒绝版本倒退，只原子替换相同或更高版本的完整快照，失败或离线时保留最后一个完整版本。
- 恶意 RSS/AI 输出包含脚本、`file://`、自定义协议或提示注入。客户端只把内容当数据，编码/净化后渲染，不执行模型指令或自动打开链接。
- 恶意正文把伪造 system/tool 指令或 DATA 边界写进文章，试图劫持摘要/翻译。客户端只把有界正文放进不可信 DATA，模型无工具权限；结果按纯文本/类型化块校验并只写本机缓存，正文变化、目标语言、模型和提示版本共同隔离缓存键。
- 恶意 RSS/Atom 使用 DTD/外部实体、超大文档/条目集合、脚本块、危险 enclosure 或通过追踪参数制造重复身份。解析器在物化前限制字节和 XML 字符数、禁用 DTD/解析器、限制条目及字段集合；正文转为纯文本，链接仅接受 HTTP/HTTPS。稳定身份优先使用发布方 id/guid，其次使用仅删除明确追踪参数的 URL，避免破坏签名 query 或把不同内容错误合并。
- Feed 服务利用条件抓取制造永久空缓存、跨主机泄露验证器、重定向 SSRF、压缩炸弹或重试风暴。客户端仅在实际发送 ETag/Last-Modified 后接受 304，200 必须先事务写入条目再提交新验证器；跨 authority 跳转清除验证器并重新解析/钉住地址。压缩与解压大小、MIME、总超时、重定向、批量和并发均有上限；失败只保存固定错误码，并以 1 分钟至 6 小时指数退避，429 的 Retry-After 同样受上限约束。
- 恶意正文图片通过 DNS rebinding、私网重定向、SVG 脚本、伪造 MIME、巨型载荷或重复失败请求攻击客户端。图片缓存命中优先且不解析 DNS；网络未命中逐跳复用 Feed 地址策略与固定-IP 连接，禁用代理/Cookie/自动重定向，只接受 MIME 与魔数一致的有限位图格式。全局并发、单资源、每篇资源数和网络字节均有上限，切换文章传播取消；失败 URL 短期抑制重试并显示本地占位。
- 恶意全文页面通过 DNS rebinding、私网重定向、压缩炸弹、编码欺骗、巨型/深层 DOM、脚本/表单/iframe、危险协议或提示注入文本攻击客户端。全文下载逐跳复用 Feed SSRF 策略与固定-IP 连接，限制 HTML MIME、总超时、跳转、下载/解压大小和同主机并发；解析前后限制节点、正文块和文本总量。第三方 DOM 库只处理内存字符串且没有网络能力，输出是类型化白名单块，URL 只接受无凭据的 HTTP/HTTPS；提示注入只作为惰性正文文本保留，不获得工具或指令权限。
- 恶意管理员规则尝试注入脚本、SQL、命令、任意 URL、灾难性正则或超量条件/动作。Worker 与 Core 使用相同的封闭字段/操作符/动作语义和显式数量/长度上限；无参数动作拒绝载荷，正则拒绝反向引用/前后查找并在本机使用 100 ms 非回溯引擎。发布采用 admin RBAC、独立规则集 `If-Match`、幂等键、不可变版本和最小审计；普通用户只能读取 ACTIVE。
- 攻击者重放规则、租约或进程内通知，试图重复隐藏、标记、调用 AI、下载媒体或创建通知。确定性计划使用条目/规则版本和稳定动作幂等键；运行账本、动作租约、媒体来源台账和通知表分别拒绝重复，旧租约持有者不能提交，重启后只恢复未完成状态。
- `SendToMedia` 被用于 SSRF、MIME/扩展名欺骗、巨型文件、慢速流或临时文件残留。执行前重新确认条目及 Feed/分类启用状态，只接受 P1-17 白名单音视频；下载逐跳钉住公网地址，限制重定向、并发、512 MiB、10 分钟和专用临时目录，并以容器魔数复核。拒绝、失败、超限和取消不创建媒体任务且清理临时文件；成功才原子登记来源和任务。
- 恶意音频条目借页面选择自动连接追踪源、伪装格式进入播放器、用迟到事件污染另一条目的进度，或诱导用户无确认下载。音频页首次进入和选择只读取本地条目；仅明确播放才接受附件分类器判定为允许 URL、完整类型验证且为 Audio 的 enclosure。切换/释放关闭旧播放器，ViewModel 还按来源 URL 丢弃迟到状态；进度只写本机档案。强制 Audio 无可信 enclosure、系统解码失败或断流时不直接打开附件，只能经两步确认把安全原文交给默认浏览器。转写必须另行点击并继续通过 `SendToMedia` 的逐跳网络、容器、大小、取消和幂等边界。
- 保留任务误删用户收藏、标签、私人阅读状态或仍在处理的条目，或条目/FTS 在中途失败后不一致。清理只能从设置页先预览再显式确认，统一候选 SQL 排除 `favorites`、`entity_tags`、任意 `user_entry_states` 和全文/AI/规则/媒体活动任务；每批最多 5000 条，关联账本、资源索引、条目和 FTS 在同一 SQLite 事务边界内处理。图片文件删除与缓存写入/LRU 维护共用互斥门闩，只移除索引不再引用的内容哈希。取消停止后续批次；磁盘空间不足或数据库忙碌只跳过 `VACUUM`，不会把已完成清理伪装成完整回滚。
- 恶意 OPML 使用 XXE、深层 outline、超大属性/文件、重复 URL 或重定向后的目录冲突，或诱导导出凭据。客户端在物化前限制为 2 MiB、禁用 DTD/外部实体并限制字符数、outline、Feed、深度和属性；预览默认不提交，重复/冲突/无效项不可选。选中项在批量写入前逐项复用 SSRF 防护发现服务并对最终 URL 再分类，任一失败整批零提交；Worker 限制 1～100 个操作并原子比较版本、写资源/审计/幂等结果。导出只允许公开目录字段，不读取账号令牌、密钥、正文或本地抓取状态。
- 恶意或巨量缓存条目试图冻结时间线、借阅读界面触发目录写入，或用快速筛选制造乱序结果。时间线每页最多读取 50 条、关键词最多 200 字符，列表采用回收虚拟化；筛选代次丢弃过期异步页，追加结果按 ID 去重。页面只依赖 ACTIVE 目录和条目只读查询，不暴露订阅编辑命令；条目正文继续按不可信纯文本交给原生只读阅读器，外链仅允许 HTTP/HTTPS 且不会自动打开。
- 大型离线库、全文索引或保留清理被用于冻结 UI。查询和统一搜索采用有界页大小/关键词/筛选，容量扫描在窗口显示后后台执行；清理先预览再确认，按最多 5000 条事务批次提交并传播取消。P1 最终验收以 10,000 条 Feed、1,000 个收藏和混合媒体验证离线查询/搜索 2 秒、预览 10 秒、清理 60 秒预算。
- 首页聚合被停用 Feed、旧早报重复迁移或损坏 favorites 数据污染。首页查询显式使用 ACTIVE Feed 投影，旧 `news_articles` 仅作为本地兼容读取，展示层按规范 URL/内容指纹去重；favorites 只读取计数，不把私人收藏状态上传云端。空目录兼容种子只预填管理员表单，仍必须经过安全发现、版本和授权写入。
- 管理员健康页被恶意 Feed 状态或重复点击利用来泄露响应/网络细节或制造重试风暴。状态仓储只返回本地固定错误码，ViewModel 映射为有限类别并隐藏响应内容；健康列表读取所有目录 Feed 但不包含令牌或正文，重试命令由单一异步命令串行化，并继续经过 Feed 刷新的 SSRF、大小、超时、解析和单 Feed 门闩策略。
- 攻击者替换 GitHub 上的 JSON 或安装包。任一签名、大小、哈希不匹配即中止，且不能由远端配置替换客户端信任公钥。
- 用户导入伪装成模型的任意大文件。先检查文件名、大小、可读性和模型头，不把路径拼接进 shell；超限拒绝。
- 数据库迁移中断或磁盘已满。迁移前一致性备份、事务回滚、保留原库并给出恢复入口。

## 隐私最小化

云端允许字段仅限账号 ID、用户名规范化值、密码摘要、角色、邀请码摘要/策略、额度、聚合用量、令牌摘要、禁用状态、共享分类/Feed 配置、目录与规则集版本、AI 策略、受限规则定义/不可变版本、幂等请求摘要/结果和安全审计元数据。共享 Feed 配置仅含 URL、显示名、分类、视图/全文/刷新/排序/启用策略；规则仅含白名单字段、操作符、值和动作，不含匹配到的条目数据。禁止字段包括新闻正文/全文、AI 摘要或译文、字幕、音频/视频、用户文件名、设备名、完整本地路径和私人阅读/收藏状态。

## 安全发布门禁

- 搜索仓库中疑似 Key、密码、私钥和 bearer token；命中必须人工解释或移除。
- 依赖漏洞与许可证审查无未处置的高危项。
- Worker 对认证、授权、401/403 区分、限流、并发额度、目录/规则版本冲突、幂等重放/错用、目录与规则 ACTIVE/ALL 隔离、超前版本拒绝和响应字段白名单有自动测试。
