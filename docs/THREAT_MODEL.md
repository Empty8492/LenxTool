# Lenx 工具箱威胁模型

## 资产

- 用户自备 Groq/DeepSeek Key、登录/刷新令牌、邀请码和管理员权限。
- 共享服务商 Key、每日额度、审计完整性和签名更新链路。
- 本地新闻、收藏、字幕、媒体任务、用户文件路径和模型。
- 发布私钥（仅离线环境存在，永不进入客户端、Worker 或仓库）。

## 信任边界

1. WPF 输入、剪贴板、拖放文件与外部链接进入客户端。
2. 客户端与新闻源、Groq、DeepSeek、GitHub/镜像和 Worker 之间的 HTTPS。
3. WebView2 中不可信 HTML/Markdown 与本机应用之间的边界。
4. Worker 与匿名客户端、已认证用户、D1、Groq/DeepSeek Secret 之间的边界。
5. 更新清单/安装包从发布环境进入客户端执行环境。
6. SQLite、DPAPI 文件、日志、模型和临时媒体位于同一 Windows 用户边界内。

## STRIDE 与控制

| 威胁 | 主要滥用场景 | 控制与测试 |
|---|---|---|
| 冒充 | 窃取 refresh token、伪造管理员、伪造服务商 | 短 access token、刷新轮换与撤销、RBAC 每端点校验、TLS、请求 ID |
| 篡改 | 修改 D1 用量、SQLite、更新清单/安装包 | 参数化 SQL、事务、条件额度更新、签名清单、SHA-256、内置公钥 |
| 抵赖 | 管理员否认发码/改额，用户否认共享调用 | 仅记录元数据的审计事件、操作者/目标/时间/请求 ID；禁止记录正文 |
| 信息泄露 | Key 进入 DB/日志，音频落云，WebView2 读取本机 | DPAPI CurrentUser、日志过滤、Worker 不落盘、禁脚本/受控导航、最小响应字段 |
| 拒绝服务 | 巨型 JSON/文件、热点源挂起、无限 AI、注册爆破 | 输入大小上限、流式处理、每源超时/取消、队列并发 1、速率限制、每日额度 |
| 权限提升 | 普通用户调用管理员端点、客户端篡改 role | 角色只以服务端签名令牌/D1 为准；每个管理员操作服务端授权和审计 |

## 关键滥用用例

- 同一用户并发发起多个共享转写，试图全部在扣费前通过。服务端必须原子预留额度；无余额的请求在调用 Groq 前失败。
- 恶意 RSS/AI 输出包含脚本、`file://`、自定义协议或提示注入。客户端只把内容当数据，编码/净化后渲染，不执行模型指令或自动打开链接。
- 攻击者替换 GitHub 上的 JSON 或安装包。任一签名、大小、哈希不匹配即中止，且不能由远端配置替换客户端信任公钥。
- 用户导入伪装成模型的任意大文件。先检查文件名、大小、可读性和模型头，不把路径拼接进 shell；超限拒绝。
- 数据库迁移中断或磁盘已满。迁移前一致性备份、事务回滚、保留原库并给出恢复入口。

## 隐私最小化

云端允许字段仅限账号 ID、用户名规范化值、密码摘要、角色、邀请码摘要/策略、额度、聚合用量、令牌摘要、禁用状态和安全审计元数据。禁止字段包括新闻正文、AI 报告正文、字幕、音频/视频、用户文件名与完整本地路径。

## 安全发布门禁

- 搜索仓库中疑似 Key、密码、私钥和 bearer token；命中必须人工解释或移除。
- 依赖漏洞与许可证审查无未处置的高危项。
- Worker 对认证、授权、限流、并发额度和响应字段有自动测试。
- 客户端对错误映射、DPAPI、数据库迁移、HTML 编码和更新验签有自动测试。
- 发布私钥仅由离线签名步骤读取；CI/客户端只读取公钥。
