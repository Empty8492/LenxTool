# Lenx 工具箱使用说明

## 安装与首次启动

1. 运行 `LenxTool_Setup.exe`。
2. 安装器会静默检查 WebView2 Runtime，可选创建桌面快捷方式。
3. 首次启动会在 `%LocalAppData%\LenxTool` 创建数据库、备份、日志、模型、输出和更新目录。
4. 不需要另行安装 .NET。

便携版解压后运行 `LenxTool.exe`。便携版程序文件可移动，但用户数据库与密钥仍固定保存在 LocalAppData，以便升级和多版本共用。

## 全局操作

- `Ctrl+K`：打开命令面板。
- 侧栏：进入首页、资讯中心、媒体工作台、文档与数据、历史与数据、设置。
- 设置可切换深色模式和减少动画；点击“保存外观”后，重启会自动恢复。

## 资讯中心

资讯中心分为“每日早报”和“热点趋势”两个分段标签页。进入“每日早报”时默认显示当天内容；需要查看历史早报时，在右上角“选择日期”下拉框选择已有缓存日期。若当天没有缓存，页面会自动选择最近一个可用日期。正文使用原生 WPF 富文本视图，可显示封面图、标题、列表和可点击链接，不依赖 WebView2。旧版本保存的纯文本缓存需要点击一次“刷新今日资讯”才能补齐图片和链接；刷新会同时更新早报与趋势。富文本正文会持久化，封面仍从来源站点加载，因此完全断网时正文可读但封面可能不显示。部分来源失败时仍显示其他来源或本地缓存。

### AI 解读与趋势报告

1. 在“设置”中填写自备 DeepSeek Key，并点击“加密保存”。
2. 在“每日早报”页点击“生成 AI 解读”，可分析当前选中日期的早报。
3. 在“热点趋势”页点击“生成趋势报告”，可汇总当前缓存热点。
4. 在“AI 报告”页查看报告正文、模型、生成时间和 token 用量。

报告请求可取消，生成结果和用量仅写入本地 SQLite，并可被全局搜索检索。模型输出按纯文本显示，不执行 HTML、脚本或其中的指令。AI 可能产生错误，请结合原始资讯核验。

## 媒体工作台

### 使用 Groq

1. 打开“设置”，在“自备 Groq Key”中输入 Key 并点击“加密保存”。
2. 回到媒体工作台，识别方式选择“Groq Whisper”。
3. 点击“导入媒体”，可多选音频或视频。
4. 点击“开始任务”。长音频会自动重叠分片。
5. 完成后点击“打开输出目录”。

### 使用本地 Whisper

1. 准备兼容 whisper.cpp 的 `ggml-*.bin` 模型。
2. 点击“导入模型”。应用会复制模型到 `%LocalAppData%\LenxTool\Models` 并计算 SHA-256。
3. 选择“本地 Whisper”与模型后开始任务。

模型不会被上传，也不会进入安装包。本地识别依赖 CPU 和模型大小，首次加载大型模型可能较慢。导入媒体后任务立即以“Queued”状态写入数据库；可随时点“取消”，失败或取消的任务可在最近任务中点击“重试”。

## 文档与数据

- 将文本粘贴到左侧，选择 JSON、Base64、URL 或文本清理操作。
- “SHA-256 文件校验”会弹出文件选择器，结果显示在右侧。
- “Word 转 PDF”需要本机安装 Microsoft Word；选择源文档和输出 PDF 后自动转换并打开目录。

## 历史与数据

- “全局搜索”页签可搜索已缓存的早报、热点和 AI 报告；输入关键词后按 Enter 或点击“搜索”。
- 选择结果可查看摘要、来源和缓存时间；有来源地址的早报或热点可用系统默认浏览器打开，应用只接受 HTTP/HTTPS 链接。
- “任务历史”页签用于查看媒体任务状态、模型和错误说明。
- 有输出的任务可直接打开文件。
- “立即备份”在 `Data\Backups` 创建一致性备份。
- “恢复备份”会先备份当前数据库、验证所选备份，再执行恢复。

## 更新

应用启动后后台检查签名清单。也可在设置页手动检查。点击“下载并安装”表示确认更新；下载完成后应用验证文件大小、SHA-256 和离线发布签名，然后退出、静默覆盖安装并重启。

## 数据位置与卸载

```text
%LocalAppData%\LenxTool\Data       数据库与备份
%LocalAppData%\LenxTool\Models     本地 Whisper 模型
%LocalAppData%\LenxTool\Secrets    DPAPI 加密密钥
%LocalAppData%\LenxTool\Output     字幕输出
%LocalAppData%\LenxTool\Logs       脱敏日志
%LocalAppData%\LenxTool\Updates    已下载更新
```

卸载默认保留以上数据。需要彻底清理时，请先在应用内备份，再由当前 Windows 用户手动删除 `%LocalAppData%\LenxTool`。

## 常见问题

- 认证失败：重新保存 Groq Key，确认 Key 未过期且有模型权限。
- 429：等待页面显示的 Retry-After，或切换本地 Whisper。
- 断网：资讯显示缓存；Groq 不可用，本地工具和本地 Whisper不受影响。
- AI 报告认证失败：在设置中重新保存 DeepSeek Key，并确认账号余额和 `deepseek-v4-flash` 模型权限。
- 视频无法转换：确认 Windows Media Foundation 支持其封装与编码；可先转为 WAV/MP3。
- 本地模型失败：确认文件名是 `ggml-*.bin`、文件完整并与 Whisper runtime 兼容。
- Word 转 PDF 不可用：安装桌面版 Microsoft Word，或由未来的 `IDocumentConverter` 适配器接入其他引擎。
