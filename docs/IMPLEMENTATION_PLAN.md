## 2026-07-31 独立候选：洛克王国世界每日清体力自动化

  - 前置：核对游戏最新用户协议，固定目标客户端/窗口/分辨率，取得用户提供的完整操作步骤与测试截图，先完成不发送输入的识别 PoC。
  - 详细候选、许可证和验收闸门见 [GAME_AUTOMATION_BACKLOG.md](plans/GAME_AUTOMATION_BACKLOG.md)。

## 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 公共热点接口变更或反爬 | 高 | 每源适配器、短超时、缓存、部分成功、可配置停用 |
| Word 转 PDF 保真与授权 | 高 | `IDocumentConverter` 隔离，清晰报告运行时能力，不承诺无损 |
| 本地 Whisper/native 体积 | 高 | 运行时与模型分离，模型导入，不进主安装包 |
| D1 并发额度竞争 | 高 | 条件更新/预留状态机、幂等请求 ID、并发测试 |
| 更新供应链攻击 | 高 | 离线签名、内置公钥、SHA-256、HTTPS、拒绝降级 |
| WPF/WebView2 DPI 与可访问性 | 中 | 语义样式、最小尺寸、自适应触发器、键盘/DPI 手测 |
| 外部工具与 CI 环境不足 | 中 | 能力探测、可操作错误、将依赖验证纳入发布脚本 |
