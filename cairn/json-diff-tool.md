# JSON 双栏结构 Diff

## 当前状态

Independent-01 于 2026-08-10 完成。入口位于“文档与数据”页的“JSON 结构 Diff”页签，复用 Core `JsonToolkit`，不依赖 SQLite、网络、模型服务或 Worker。

## 行为边界

- 左右输入独立校验；一侧错误不会覆盖另一侧状态。
- 合法 JSON 根值 `null` 与解析失败使用独立有效性状态区分，可正常格式化、压缩、排序和比较。
- 差异按 JSON 字符串转义的方括号路径显示新增、删除、修改及左右值；`$["a.b"]` 与 `$["a"]["b"]` 不会碰撞，交换输入会使旧结果失效。
- 每侧最多 2,097,152 个字符，差异数量上限为 500；恰好 500 处不标记数量截断，第 501 处才标记。
- 单路径最多 1,024 个字符，超长链路以确定性的 `path-sha256` 标识代替；全部已显示路径累计最多 256 KiB，路径预算可能让实际显示条数少于 500，状态必须报告实际条数。
- 单个值预览最多 2,048 个字符；生产滚动区给列表提供有限视口并启用 WPF 回收虚拟化，500 行结果不会一次实现全部容器。
- `JsonException.BytePositionInLine` 是 UTF-8 字节偏移，用户文案不得称为字符“列”。

## 并发与取消约束

比较只使用命令启动时捕获的左右快照并在后台执行。两侧校验与 Diff 共用每侧唯一解析树；严格 UTF-8 编码前后检查取消，异步解析流每次最多读取 64 KiB，对象与数组遍历继续传播同一取消令牌。编辑、交换和显式取消均须使当前代际失效。

后台计算完成不代表结果仍可发布：continuation 回到 UI 后必须再次检查取消令牌、任务代际、输入修订和左右快照。输入修订是独立单调计数，不能只比较字符串，否则 A→B→A 会让旧快照伪装成当前输入。

## 回归证据

- Core：根 `null`、点号/引号/空属性名路径、类型/值、解析与遍历取消、单路径/总路径预算、摘要去碰撞、256 KiB 长祖先 × 500 差异的线程分配上限，以及 500/501 精确数量边界。
- ViewModel：独立错误、路径预算提前截断的实际条数、超限、交换、UTF-8 字节位置、完成后取消、A→B→A。
- 真实 WPF：最小 920×620 `MainWindow` 中的生产滚动区、原生 Automation Peer、Tab 焦点、绑定命令、500 行回收虚拟化、等效 200% 布局下右栏/列表可达与深浅主题。

等效 200% `LayoutTransform` 是稳定组件级证据，不替代正式发布矩阵中的真实 Windows 200% DPI/文本缩放人工观察。仓库既有 `SelectionControlsWpfRuntimeTests` 仍可能在 `CalendarAutomationPeer.GetChildrenCore` 出现环境基线失败；判断 JSON Diff 回归时须独立进程运行其真实 WPF 用例。
